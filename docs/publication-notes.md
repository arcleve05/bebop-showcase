# Publication boundaries and provenance

The repository is a **curated personal portfolio**: executable excerpts or adaptations plus synthetic tests, not private source repositories or preserved commit history.

| Public example | Source and publication treatment |
| --- | --- |
| Dependency contract | Anonymized excerpts from personal `bebop-control/src/backlog/dependencyBlock.js`, with public test adaptations and further portfolio hardening |
| Execution lease | Personal `bebop-control/integrations/bebop-run/code_lease.py` policy excerpt and synthetic tests; no live process ownership code |
| Evidence scoring | Standalone adaptation from personal `bebop-bench/src/bebop_bench/grading.py`; consumes supplied outcomes rather than executing untrusted processes |
| Live-state cache | Adaptation of personal `bebop-dashboard/src/state-cache.js` with synthetic adapter tests and explicitly documented validation boundaries |
| Synthetic release evidence gate | Newly written public example; **not** sourced from an employer, a customer or existing Bebop deployment |

**Separate professional statements:** The [quality leadership page](quality-leadership.md) is based on resume claims and does not assert that professional employer implementations were copied into or powered by Bebop.

**Excluded:** employer/customer source and records; private topology, credentials, model weights, customer data, internal operational traces, live endpoint addresses and complete private repository histories.

**Claims:** Passing public component tests does not establish a deployed unattended end-to-end pipeline or prove past company-wide outcomes. Dated private validation results are historical reports only. Examples modified for publication should not be characterized as byte-for-byte original extracts.

**Rights:** Verify ownership and employment/IP requirements independently before distributing any additional source. No general reuse license is granted by default.
