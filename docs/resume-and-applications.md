## Interview guide
**What did you test?** Negative/edge cases, malformed dependency contracts, time-dependent lease behavior, independent grading, and adversarial escapes.

**How do you handle uncertainty?** Bind actions to exact identities; never blindly retry a potentially completed mutation; reconcile against authoritative evidence.

**What is the project status?** Individual components are implemented and tested. Some workflows are experimental or staged. Don't conflate passing component tests with a deployed end-to-end autonomous production system.
